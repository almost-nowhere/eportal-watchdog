# eportal-watchdog

装在 OpenWrt 路由器上的校园网自动认证看门狗，适用于**锐捷 ePortal 网页认证**（登录页地址里带 `/eportal/` 的那种）。

它做三件事：

1. **掉认证自动重登。** 常驻后台，每 3 秒检查一次，发现被重定向到登录页就用你的账号重新登录。
2. **夜间断网时关掉 5G Wi-Fi。** 学校断网后路由器的 Wi-Fi 还亮着，手机会连着一个上不了网的 Wi-Fi 干等。看门狗在认证服务器明确回复"不在认证时段内"后关掉 5G 射频，手机随即回落到流量；2.4G 保持开启，智能插座之类的设备不受影响。
3. **早上准点恢复。** 到点自动登录并重新打开 5G。

断网期间它只是等待，不做任何绕过断网的事。

## 适用条件

- 学校用的是锐捷 ePortal 网页认证。用锐捷客户端（802.1X）认证的学校不适用。
- 路由器运行 OpenWrt 24.10 或更新版本。更老的版本缺少 ucode 的 `log` 模块。
- **只在 OpenWrt 25.12.5（mt7621 平台）上实际验证过。** 其他版本和平台理论可用，欢迎反馈。
- 夜间断网时段默认按 00:00–06:00 处理。不同的话见下文"修改断网时段"。

## 安装

用 SSH 登录路由器后执行：

```sh
wget -O /tmp/install.sh https://raw.githubusercontent.com/almost-nowhere/eportal-watchdog/main/install.sh
sh /tmp/install.sh
```

脚本会检查并补装依赖，然后询问校园网账号和密码，最后启动服务。

如果路由器访问不了 GitHub，就在电脑上下载整个仓库，拷到路由器再装：

```sh
scp -O -r eportal-watchdog root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sh /tmp/eportal-watchdog/install.sh"
```

再次运行 `install.sh` 只会更新脚本，保留已有的账号配置。

## 使用前请知道

- **密码是明文保存的**，在路由器的 `/etc/config/campus_network` 里（权限 600）。校园网账号常常和教务系统、邮箱共用同一个密码，请确保路由器的管理密码足够强，不要把路由器交给别人管理。
- **登录请求是明文 HTTP**。这是门户本身的工作方式，和你在浏览器里登录时一样。
- **请遵守本校的网络管理规定**，只使用你自己的账号。有的学校不允许在宿舍使用路由器，装之前请自行确认。
- 学校更换认证系统或接口后它会失效。作者不承诺持续维护。

## 配置

配置文件是 `/etc/config/campus_network`，改完执行 `service campus-watchdog restart`。完整示例见 [campus_network.example](campus_network.example)。

| 选项 | 必填 | 说明 |
|---|---|---|
| `enabled` | 是 | `1` 启用，`0` 停用 |
| `username` | 是 | 校园网账号 |
| `password` | 是 | 校园网密码 |
| `portal_server` | 否 | 门户地址（IP 或域名）。不填则使用跳转页里给出的地址 |
| `radio_5g` | 否 | 夜间要关闭的射频名。不填则自动识别 5G 射频 |
| `night_wifi_off` | 否 | 填 `0` 表示夜间断网时不关 Wi-Fi |

建议填上 `portal_server`：填了之后，密码只会发往你指定的地址。

### 修改断网时段

打开 `/usr/bin/campus-watchdog.uc`，修改"可调参数"一节里的两个常量：

```js
const NIGHT_START_MS = 0;                    // 夜间窗口起点 00:00:00
const WAKE_MS = (6 * 3600 + 1) * 1000;       // 晨间唤醒时刻 06:00:01
```

是否进入夜间休眠只看认证服务器的回复，不看时间，所以周末不断网的学校不需要额外设置。这两个常量只决定"睡到几点醒"。

## 日常维护

```sh
logread -e campus-watchdog          # 看日志
service campus-watchdog restart     # 重启
sh install.sh uninstall             # 卸载（配置文件会保留，需要手动删除）
```

日志是中文的，正常情况下只在状态变化时写一条，例如：

```
看门狗已启动
认证成功，已上线
认证服务器回复“不在认证时段内”，确认夜间断网。关闭 5G，休眠到 06:00:01
5G Wi-Fi 已关闭，手机将回落到流量
06:00:01 到点，开始晨间认证
认证成功，已上线
5G Wi-Fi 已开启
```

## 工作原理

- **在线检测**：每 3 秒 ping 一个公网 DNS 节点（在 8 组不同厂商的节点间轮换）；约每分钟再用手机厂商的联网检测地址做一次 HTTP 204 确认。只靠 ping 不够，因为有的校园网在未认证时也放行 ICMP。
- **判断掉线原因**：HTTP 探针被重定向到门户页，说明掉了认证，立刻登录；探针和 16 个节点全都不通，说明是上游断了，只等待不登录。
- **登录失败后的重试间隔**：普通失败先 30 秒、三次后 2 分钟；密码错误 5 分钟；欠费 2 分钟。间隔拉长是为了不给认证服务器添负担，也避免密码填错时反复提交。
- **夜间休眠**：只在认证服务器明确回复"不在认证时段内"时才进入。休眠期间每 5 分钟做一次 HTTP 探测，网络提前恢复就提前醒。
- **没有硬件时钟的路由器**：开机后在 NTP 对表之前系统时间不可信，这段时间里不按时钟判断，改为每 10 分钟询问一次认证服务器。
- **关 5G 不写闪存**：通过 ubus 在运行时关闭射频，不修改无线配置，路由器重启后 5G 自然是开的。停止服务时也会把 5G 恢复。

脚本用 OpenWrt 自带的 ucode 编写，单文件，注释写得比较细，方便自己改。
